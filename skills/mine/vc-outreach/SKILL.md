# VC Outreach

Complete the requested part of investor outreach: a target list, message draft, meeting preparation, pipeline review, or active raise. A narrow request does not require a deck, strategy memo, data room, CRM, or fundraising calendar first.

| Task | Relevant reference |
| --- | --- |
| Target selection | `references/targeting.md` |
| Intro/email drafting | `references/getting-the-meeting.md` |
| Meeting preparation/debrief | `references/meetings.md` |
| Active pipeline | `references/process-and-pipeline.md` |
| Diligence/close | `references/diligence-and-close.md` |

Read the matching sections; reuse the founder's materials and ask only for missing facts that change the result. Verify current partner roles, fund thesis/check/stage, portfolio conflicts, and contact details before presenting them as current. Corpus numbers and outreach cadences are dated heuristics, not universal targets or stop rules.

For an active raise, size the list to actual fit, access, and founder capacity; research priority targets deeply, keep a dated next step, prepare relevant proof, and record material feedback. Use stage-appropriate disclosure, revocable data-room access, and consistent forecasts/cap-table facts. Related deck/strategy skills are useful only for a distinct missing deliverable.

Draft or queue outreach by default. Send messages, intro requests, calendar invitations, or announcements only with explicit authorization already covering that action. Never invent traction, investor interest, deadlines, or warm relationships. A prepared email/list is a complete drafting deliverable; a wire or term sheet is not required to finish that request.
